Here's the set of default keybindings available in Wave. It is split into sections.
Some keybindings are always active. Others are only active for certain types of blocks.

Note that these are the MacOS keybindings (they use "Cmd"). For Windows and Linux,
replace "Cmd" with "Alt" (note that "Ctrl" is "Ctrl" on both Mac, Windows, and Linux).

Chords are shown with a + between the keys. You have 2 seconds to hit the 2nd chord key after typing the first key. Hitting Escape after an initial chord key will always be a no-op.

## Customizing Global Keybindings

The global keybindings above can be remapped. Create a `keybindings.json` file in your Wave config
directory (`~/.config/waveterm/keybindings.json` on macOS/Linux, `%LOCALAPPDATA%\\waveterm\\keybindings.json`
on Windows) that maps **action ids** to the key(s) you want. You only need to list the actions you want
to change — everything else keeps its default. Changes apply live, no restart required.

```json
{
    "app:newblock": "Cmd:Shift:n",
    "app:newtab": ["Cmd:t", "Cmd:Shift:t"],
    "app:togglemultiinput": "none"
}
```

A value may be a single key descriptor string or an array of them. Use `"none"` (or `""`) to disable an
action entirely. Key descriptors are modifiers joined by `:` followed by the key, e.g. `Cmd:Shift:n`,
`Ctrl:Shift:ArrowUp`, `F2`. Modifiers are `Cmd`, `Ctrl`, `Shift`, `Alt`, `Option`, `Meta` (order does not
matter). Physical-code keys are written as `c{Code}`, e.g. `Ctrl:Shift:c{Digit1}`.

#### Prefix chords (tmux-style)

A binding may also be a two-key **chord**: a prefix combo and a second key separated by a space, e.g.
`"Ctrl:b c"`. Pressing the prefix arms chord mode (you have 2 seconds to press the second key). Multiple
actions can share a prefix, which makes it easy to build a [tmux](https://github.com/tmux/tmux)-style
layout under a single `Ctrl-b` prefix:

```json
{
    "app:newtab": "Ctrl:b c",
    "app:magnifyblock": "Ctrl:b z",
    "app:renametab": "Ctrl:b ,",
    "app:focusblockleft": "Ctrl:b h",
    "app:focusblockright": "Ctrl:b l",
    "app:splitblockright": "Ctrl:b ArrowRight"
}
```

Note: a chord prefix swallows that key combo from the focused block (just like tmux's prefix), so choose a
prefix you don't need to type otherwise.

:::info
Only the **global** keybindings listed above are customizable today. Block-specific keybindings (File
Preview, Web, Terminal, etc.) are not yet remappable. The <Kbd k="Escape"/> key is reserved.
:::

## File Preview Keybindings

| Key                                       | Function                                                                                           |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------- |
| <Kbd k="[text]"/>                         | Any regular character (e.g. "a", "b") will filter the file list                                    |
| <Kbd k="Escape"/>                         | Clears the filter                                                                                  |
| <Kbd k="ArrowUp"/> / <Kbd k="ArrowDown"/> | Change file selection up/down                                                                      |
| <Kbd k="Enter"/>                          | Open the currently selected file/directory                                                         |
| <Kbd k="Cmd:ArrowUp"/>                    | Move "up" a directory (parent directory)                                                           |
| <Kbd k="Cmd:ArrowLeft"/>                  | Back, move to the previously selected file/directory                                               |
| <Kbd k="Cmd:ArrowRight"/>                 | Forward (opposite of back)                                                                         |
| <Kbd k="Cmd:o"/>                          | Open a new file (accepts relative paths to the current directory)                                  |
| <Kbd k="Cmd:s"/>                          | When file editor is open, save file                                                                |
| <Kbd k="Cmd:e"/>                          | For files that can be previewed or edited (markdown, CSVs), switches between preview and edit mode |
| <Kbd k="Cmd:r"/>                          | When file editor is open, revert changes                                                           |
